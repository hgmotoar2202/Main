# Prompt inicial para Claude Code + BMAD

Actúa como coordinador técnico del proyecto INSURE AI. El PDF en `docs/contexto/` es el
contexto inicial y no sustituye los artefactos oficiales de BMAD.

REGLAS
1. Inspecciona el repositorio, la versión instalada de BMAD y los módulos/workflows realmente disponibles.
2. No inventes agentes, comandos ni módulos. Verifica la documentación instalada.
3. Ejecuta primero Analysis y Planning. No generes código de producto todavía.
4. Identifica ambigüedades, riesgos, dependencias, decisiones pendientes y supuestos.
5. Nunca uses datos reales sensibles. La IA no decide cobertura, responsabilidad, diagnóstico ni autorización.
6. Todo cambio queda trazado en GitHub (historias, commits, PR, releases).

PRIMER ENTREGABLE: informe de diagnóstico con artefactos BMAD disponibles y faltantes,
plan de instalación, preguntas abiertas priorizadas, riesgos, estructura de repositorio,
plan de Sprint 0 y criterios objetivos de autonomía.
Espera aprobación del Product Owner antes de implementar.
